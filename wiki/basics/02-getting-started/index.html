インストール

Windows

  1. GitHub Releases から HrdayaFlow-Setup-x.y.z.exe (MSI/NSIS) をダウンロード
  2. インストーラを起動 (SmartScreen が出たら「詳細情報」→「実行」)
  3. 既定で C:\Users\<user>\AppData\Local\Programs\HrdayaFlow\ にインストール
  4. スタートメニューから「HṛdayaFlow」を起動

⚙ MSI のサイレントインストールは msiexec /i HrdayaFlow.msi /quiet で可。

macOS / Linux

ビルド済みバイナリは未配布。開発リポジトリから flutter build macos / flutter build linux で生成してください。詳細は 04-developer-guide › セットアップ。

初回起動

初回起動時のみオンボーディングウィザードが出ます (現状は最小)。

  1. 言語選択 — 日本語 / English
  2. テーマ選択 — Light / Dark / System
  3. データフォルダ — 既定: <Documents>/HrdayaFlow/
  4. サンプルマップを開く — チェックすると welcome.hrf が起動

5 分でわかる基本操作

① 新規マップを作る

⌨ Ctrl+N または ファイル → 新規

② ノートを置く

🖱 キャンバスをダブルクリック → 空のテキストノードができる → そのままタイプ

③ ノートを繋ぐ

🖱 ノードの右上端にホバー → ハンドルが出る → ドラッグして他のノードへ → エッジ完成

④ 整える

⌨ Ctrl+; でグリッド表示、Shift+; でスナップ ON/OFF。複数選択して 整列 でビシッと揃う (04-groups-and-containers)。

⑤ 保存する

⌨ Ctrl+S で .hrf (ZIP) として保存。初回は保存先を聞かれる。以降は自動上書き (11-files-and-interop)。

⑥ 共有する

  • メール添付 — .hrf を渡す (受け取り側も HrdayaFlow が必要)
  • PDF / PNG / SVG — メニュー → エクスポート → 形式選択 (11-files-and-interop › export)
  • Markdown — Obsidian や Notion にコピペ用 (11-files-and-interop › export)

サンプルマップで遊ぶ

docs/user-manual/manual-demo.md の手順で welcome.hrf を開くと、12 種のノードと 3 種のエッジを使ったサンプルが表示されます。各ノードを選んで Inspector でプロパティを触ると、書式の効きが体感できます。
