インストール

Windows

配布しているのは MSI インストーラー 1 種類だけです（Windows 10 / 11 の 64bit 向け）。

  1. 公式サイトのダウンロードボタンから

HrdayaFlow-<版>-x64.msi を取得します。GitHub Releases からも同じものを入手できます

  1. ダウンロードしたファイルをダブルクリックします
  2. 「WindowsによってPCが保護されました」と出たら → ［詳細情報］→［実行］。

コード署名証明書をまだ取得していないために出る警告です。詳しくは 04-install-warning

  1. インストール先は C:\Program Files\HrdayaFlow（既定。変更可）
  2. スタートメニューの「HrdayaFlow」から起動します

⚙ 無人インストール: msiexec /i HrdayaFlow-<版>-x64.msi /qb
（/quiet でも可。既に同じ版が入っていると「変更 / 修復 / 削除」になります）

💾 必要なランタイムは同梱しています。 VC++ 再頒布可能パッケージを別途入れる必要は
ありません。WebView2 が無い環境では、インストール完了時に導入案内が開きます。

macOS / Linux

ビルド済みバイナリは未配布。開発リポジトリから flutter build macos / flutter build linux で生成してください。詳細は 04-developer-guide › セットアップ。

初回起動

設定ウィザードはありません。 起動すると、そのままキャンバスが開きます。

初回だけ、同梱のチュートリアルマップが自動で開きます（閲覧のみ）。2 回目からは開きません。
不要なら設定の「初回起動時にチュートリアルを開く」を OFF にしてください。
あとから開くときは ヘルプ ▸ チュートリアルを開く…。

言語とテーマは 設定（Ctrl+,） からいつでも変更できます。初回に選ばせる画面はありません。

保存先を決める設定もありません。マップは保存するときに自分で場所を選びます
（メニュー ▸ ファイル ▸ 名前を付けて保存）。自動保存だけは
%USERPROFILE%\.hrdaya\autosave\ に置かれます。

更新・診断・サポートについては 05-updates-and-support を参照してください。

5 分でわかる基本操作

① 新規マップを作る

⌨ Ctrl+N または ファイル → 新規

② ノートを置く

🖱 キャンバスをダブルクリック → 空のテキストノードができる → そのままタイプ

③ ノートを繋ぐ

🖱 ノードの右上端にホバー → ハンドルが出る → ドラッグして他のノードへ → エッジ完成

④ 整える

⌨ Ctrl+; でグリッド表示、Shift+; でスナップ ON/OFF。複数選択して 整列 でビシッと揃う (04-groups-and-containers)。

⑤ 保存する

⌨ Ctrl+S で .hrf (ZIP) として保存。初回は保存先を聞かれる。以降は自動上書き (11-files-and-interop)。

⑥ 共有する

  • メール添付 — .hrf を渡す (受け取り側も HrdayaFlow が必要)
  • PDF / PNG / SVG — メニュー → エクスポート → 形式選択 (11-files-and-interop › export)
  • Markdown — Obsidian や Notion にコピペ用 (11-files-and-interop › export)

サンプルマップで遊ぶ

docs/user-manual/manual-demo.md の手順で welcome.hrf を開くと、12 種のノードと 3 種のエッジを使ったサンプルが表示されます。各ノードを選んで Inspector でプロパティを触ると、書式の効きが体感できます。
