インストール時の警告 (SmartScreen) について

🚧 Beta 期のお知らせ HrdayaFlow v0.x (beta) は コード署名証明書が未取得 のため、Windows のインストール時に「Windows によって PC が保護されました」という警告が表示されます。これはアプリの安全性とは無関係で、商用版リリース時に証明書を取得して解消する予定です。

なぜ警告が出るのか

Windows の SmartScreen は、「Microsoft が信頼する発行元の証明書で署名されていないアプリ」 に対して警告を表示する仕組みです。HrdayaFlow beta は証明書未取得のため、この警告対象になります。

警告画面の例:

┌──────────────────────────────────────────┐
│ ⚠ Windows によって PC が保護されました    │
│                                          │
│ Microsoft Defender SmartScreen は認識さ  │
│ れないアプリの起動を停止しました。       │
│ このアプリを実行すると PC が危険に       │
│ さらされる可能性があります。              │
│                                          │
│   [実行しない]                            │
└──────────────────────────────────────────┘

回避手順 (Windows 10 / 11)

  1. ダウンロードした MSI をダブルクリック
  2. 上記の警告画面が表示される
  3. 中央の青字の 「詳細情報」 をクリック
  4. アプリ名 (HrdayaFlow-x.y.z-x64.msi) と発行元 (不明な発行元) が表示される
  5. 右下の 「実行」 ボタンをクリック
  6. インストールウィザードが起動 → 通常のインストール手順へ

安全性について

  • SHA256 ハッシュ検証: HrdayaFlow の auto-update 機構は MSI のダウンロード時に SHA256 ハッシュをサーバ発表値と照合 し、改竄を検知します。署名がなくても、配布経路での tamper は検出されます。
  • 配布元: MSI は GitHub Releases (https://github.com/geshpoyo/HrdayaFlow-releases/releases) からのみ配布。第三者ミラーは公式に存在しません。
  • オープン度: アプリ本体のソースは現在 private ですが、配布インフラ (このリポジトリ + GitHub Pages + Releases) はすべて public で監査可能です。

SmartScreen 警告がいつ消えるか

段階状態
現在 (beta)証明書なし → 常に警告
証明書取得後 (OV)警告は出るが「発行元: HrdayaFlow (確認済み)」と表示。DL 数累積で消える
商用版 (EV 証明書取得後)警告ゼロ。発行元名がそのまま表示

商用版リリース (v1.0 以降) で証明書取得を予定しています。

それでも警告が怖い場合

  • VirusTotal で MSI ファイルをスキャン → クリーン確認 (https://www.virustotal.com/)
  • 仮想マシン (VMware Workstation Player など、無料) で先にインストール → 動作確認 → 本番 PC へ
  • Hyper-V Sandbox (Windows 11 Pro 機能) で隔離実行

トラブルシューティング

症状対応
「詳細情報」が表示されないWindows Update 適用後に再試行。極端に古い Windows 10 では UI が異なる場合あり
「実行」を押しても何も起きない管理者権限で再試行 (右クリック → 管理者として実行)
「Windows Defender がブロックしました」一時的に Defender の Real-time protection を OFF → インストール → ON に戻す (推奨しない、最終手段)
警告ではなく完全にブロック (実行不可)組織管理デバイスの場合、IT 管理者の設定により実行不可能。個人 PC を使用
