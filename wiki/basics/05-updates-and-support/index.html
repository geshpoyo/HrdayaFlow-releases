更新・停止・診断・サポート

← インストール時の警告 | 目次 | → 03 キャンバス

新しい版がどう届くか、届かないときに何を見るか、こちらから利用を止めることがある仕組み、
そして困ったときの窓口。

自動更新の流れ

起動時と、その後 24 時間ごとに確認します。

起動（+ 24 時間ごと）
   ↓
配信フィードを取得（10 秒でタイムアウト。200 以外は「更新なし」）
   ↓ 新しい版があれば
更新ダイアログ「今すぐ / あとで」
   ↓ 今すぐ
インストーラー（.msi）をダウンロード（進捗表示）
   ↓
① sha256 を照合 — 空でも不一致でも中止
   ↓
② 未保存のタブを保存 — 保存できなければ中止（インストーラーを起動しない）
   ↓
インストーラーを起動してアプリを終了 → 上書きインストール

守りが 2 段入っています。

段何を防ぐか
sha256 照合配布物のすり替え・破損したダウンロード。ハッシュが空の配布物も拒否します
保存ガード「更新したら書きかけが消えた」。保存に失敗したらインストーラーを起動しません

署名検証（Authenticode）は既定で行いません。コード署名証明書を取得していないため、
検証を必須にすると全員が失敗します。改竄検知は sha256 で担保しています。

手動で確認する

ヘルプ ▸ マニュアルの更新を確認… はマニュアル用です。アプリ本体の更新確認は
設定 ▸ 更新 から行えます。自動更新を OFF にすると定期確認は止まります。

⚠ 更新が届かないとき（既知の制約）

現在、アプリの既定チャンネルは stable ですが、アルファ版は beta チャンネルにのみ
配信しています。既定のままだと更新が見つかりません。

対処は 2 つあります。

  • 設定でチャンネルを beta に切り替える
  • サイトのダウンロードページから新しい

インストーラーを直接取得して上書きインストールする（データは残ります）

この食い違いは把握しており、次の版で解消予定です。

閲覧のみモード（リモート停止）

重大な不具合が見つかった版を、配信側から止めることがあります。
データを壊し続けるより、いったん編集を止めてもらう方が安全なためです。

停止された版を起動すると、理由のメッセージと［閲覧のみで続行］が出ます。

できることできないこと
保存済みマップを開いて読む編集・保存
内容をコピーして退避する新規作成

保存済みのファイルには一切触れません。 アプリが書き換えたり消したりすることはありません。

ネットに繋がらないときは制限しません

配信側の情報を取得できない場合、制限をかけません（fail-open）。
機内やオフライン環境でアプリが使えなくなることはありません。
「更新を確認できませんでした（オフラインの可能性があります）」と出るだけです。

一度受け取った停止指示は、オフラインでも効き続けます。解除も配信側から行われ、
次の起動時に反映されます。

診断とフィードバック

設定 ▸ 診断とフィードバック で、不具合報告に貼り付ける情報を組み立てられます。

何が入るか

項目例
App0.0.7+4
OSwindows とビルド情報
Localeプラットフォームの言語と、アプリの言語設定
Installインストーラー / flutter run / その他
Crash logs件数とファイル名
MCP enabledtrue / false
Auto-update enabledtrue / false

何が入らないか

  • マップの中身は一切入りません。ファイル名も本文も含みません
  • ユーザー名を含むパスは ~ に置き換えられます（C:\Users\yourname\… → ~\…）

自動送信はしません

このアプリはどこにも自動でデータを送りません。コピーしたものを、あなたが
貼り付けたときだけ相手に渡ります。ログフォルダを開く導線と、直近クラッシュの
一覧も同じ画面にあります。

プライバシーの全体方針は privacy を参照してください。

困ったときの窓口

窓口向いていること言語
Discordインストールできない・起動しない・使い方がわからない日本語
GitHub Issues再現手順のある不具合、要望英語
トラブルシューティングまず自分で調べたいとき日本語

報告するときは、上の診断情報を貼ると原因の切り分けが早くなります。

同梱チュートリアル

初回起動時にチュートリアルが自動で開きます（1 回だけ。2 回目以降は開きません）。
自動で開くのが不要なら、設定の「初回起動時にチュートリアルを開く」を OFF にしてください。

あとから開くときは ヘルプ ▸ チュートリアルを開く…。

  • 実体は <appSupport>/manual/HrdayaFlowTutorial.hrf
  • 閲覧のみで開きます。うっかり書き換えて原本が変わることはありません
  • 書き込んで練習したいときは、バナーの［自分用にコピー］から複製を作ります
  • 既に開いていれば、同じタブに切り替わります（重複して開きません）

動作確認チェックリスト

  • [ ] 設定 ▸ 診断とフィードバック で診断情報をコピーでき、パスが ~ になっている
  • [ ] ネットワークを切って起動しても、編集・保存が普通にできる
  • [ ] ヘルプ ▸ チュートリアルを開く… で閲覧のみのタブが開く
  • [ ] 2 回目の起動でチュートリアルが自動で開かない
