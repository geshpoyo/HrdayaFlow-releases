04 ノード 13 種

← 03 キャンバス | 目次 | → 05 エッジ

HṛdayaFlow のキャンバスに置けるノートは 13 種類 (うち Dot はナイフで自動生成される中継ノート)。共通の Inspector で書式を変えられ、種別はいつでも切り替えられる。

ノート種別用途主な操作
Dotエッジの中継 / 集約地。ナイフ (03-edges-and-connections › ナイフでエッジリルート-dot-中継) で自動生成移動 (G / D&D / 矢印)、サイズ変更 (S / リサイズハンドル)。テキスト編集 / F2 / Ctrl+P は無効

共通プロパティ

すべてのノードに以下が備わる。

プロパティ説明
位置 (x, y) / サイズ (width, height)キャンバス座標と表示寸法
回転 (rotation)度単位
Layer表示レイヤー (lock / visibility)
Manual sized自動サイズか手動か
Sticky編集モードでもピンで固定 (移動不可)
Style ref / Style override共通スタイルライブラリ参照 / 個別上書き
MetaoriginName / originalFileName / 任意 key-value
Semantics (alt / role)スクリーンリーダー用ラベル

ノード種別の切り替え

選択 → Inspector 上部の「種別」ドロップダウン → 切替。データは保たれる範囲で変換される。

⚠ text → image のように内容構造が変わる切替は確認ダイアログ。

1. Text — プレーンテキスト

最もシンプル。1 行〜複数行のテキスト。

用途キーワード・短いラベル・ラベルだけのノード
プロパティtext / inlineMarks (B/I/U/S/range/color/link)
ショートカットダブルクリックで作成 (既定)
Inspectorフォント / 色 / サイズ / 配置 / 装飾
  • InlineMark で範囲指定の部分太字・部分色付けが可能
  • 改行: Shift + Enter で挿入、Esc で編集確定
  • 縦書きノート (writingMode: vertical-rl/lr) では: Shift + Enter は新しい列 (line) を 左隣 / 右隣 に作成する操作になる。横書きでの「次の行」が縦書きでは「次の列」に対応する。IME 変換確定中の Shift + Enter は予測変換確定として尊重されるため、改行は挿入されない

2. Markdown

CommonMark / GFM 準拠のリッチテキスト。長文ノート、AI回答の貼り付け、表やコードを含むメモ向け。

プロパティbody (インライン) または bodyRef (assets/text/<uuid>.md)
対応記法見出し / 段落 / リスト / コード / 引用 / 画像 / リンク / 表 / 太字 / 斜体
ライブラリflutter_markdown
表示設定設定 → Markdown 表示プリセット（標準 / 読みやすい）
  • 64 KB 超は自動的に bodyRef (外部ファイル) に切り出し → .hrf ZIP 内の assets/text/ に格納
  • ダブルクリックすると、キャンバス上のノートは装飾済みプレビューのまま残り、ノート直下に「Markdown 原文」編集面が開く
  • 原文への入力はプレビューへ即時反映される
  • Enter で確定、Shift + Enter で改行、Esc でキャンセル
  • 長い Markdown を編集しても、プレビューの見た目を確認しながら本文を直せる

3. Image

PNG / JPG / GIF / WebP / SVG。

プロパティasset (path) / originUrl / alt / crop (normalized rect)
入力方法D&D ファイル / D&D URL (ダウンロード) / クリップボード貼付
CropInspector で 正規化座標 (0.0-1.0) で切り出し
  • 保存時 assets/images/<uuid>.<ext> に格納
  • 50 MB を超える画像は 外部リンク参照 に自動切替 (settings で閾値変更可)

4. Link — URL

URL を 1 枚のカードにする。

プロパティurl / title / description / favicon (auto-fetch)
開くクリック → 既定ブラウザ
favicon初回読み込み時に取得 → cache

5. Video — 動画

MP4 / WebM / MOV。

プロパティasset / thumbnail / originUrl / durationSec / autoplay
ライブラリvideo_player
表示サムネイル + 再生ボタン
  • ZIP 内 assets/videos/<uuid>.<ext> に格納
  • ファイルサイズが大きいので 50 MB 閾値推奨

6. Audio — 音声

MP3 / M4A / OGG / WAV。

プロパティasset / durationSec / waveform (cached)
ライブラリjust_audio + audio_waveforms
表示波形 + 再生ボタン + 時間
  • 波形は読み込み時に生成 → assets/audio/<uuid>.waveform.json にキャッシュ

7. Checklist — チェックリスト

タスクリスト。

プロパティitems[] {id, text, done}
操作チェックボックスクリックで done 切替、+ で追加、Backspace で削除
並べ替えドラッグハンドルで並べ替え
  • Markdown ノードに「- [ ]」を書くのとは別物 (こちらはネイティブウィジェット)
  • Outline パネルにも進捗 (3/8 done) として表示

8. Code — コード片

シンタックスハイライト付き。

プロパティcode / language
ライブラリflutter_highlight
言語dart, rust, python, javascript, typescript, go, java, c, cpp, kotlin, swift, ruby, php, html, css, json, yaml, markdown, shell, sql, ... 100+
テーマアプリのライト/ダークに連動
  • 言語ピッカー (Inspector) で変更
  • タブ幅は 2 固定 (将来は設定可)

9. Embed — HTML 埋め込み

iframe で外部コンテンツ表示。

プロパティhtml (sanitized) / sourceUrl
用途YouTube / Twitter (X) / CodePen / Figma 埋め込み
セキュリティCSP sandbox + HTML sanitizer (03-troubleshooting › embed)
  • ⚠ 信頼できないソースは要注意。初回は確認ダイアログ。

10. Math — LaTeX 数式

KaTeX 風。

プロパティlatex (string) / displayMode (inline / block)
ライブラリflutter_math_fork
用途学術ノート、フォーミュラ

例: \int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}

11. Frame — 装飾矩形

「枠」だけ。中身を持たず、背景・装飾用。

プロパティlabel (任意) / fill / border / corner
用途領域名ラベル、視覚的グルーピング (実体グルーピングは Container)
操作半透明、後ろに敷く

12. Container — 折りたたみ可能な箱

子ノードを内包し、折りたたみで一時的に隠せる。

プロパティlabel / members[] (childIds) / collapsed (bool) / layoutHint
操作複数選択 → ⌨ Ctrl + G で Container 化、Ctrl + Shift + G で解除
サブマップ昇格右クリック → サブマップとして開く

詳細は 04-groups-and-containers。

13. Dot — エッジ中継

ナイフ機能で切断したときに自動生成される小さな ● 円。ファンイン / ファンアウトを 1 点に集約する。

項目内容
用途エッジの中継・視覚的な集約地 (03-edges-and-connections › ナイフでエッジリルート-dot-中継)
生成通常は Shift + 右マウスドラッグ のナイフで自動配置 (手動新規作成は v1 では想定外)
見た目塗り潰し円。初期直径 14 px (width = height、4–48 px に clamp)
移動G / ドラッグ / 矢印キー (Shift 16 px / Ctrl 64 px)
サイズS または 8 方向リサイズハンドル (中心固定・常に円)
回転R は無効
編集F2 / ダブルタップ編集なし。Inspector は種別表示のみ (読み取り専用)
親子化Ctrl + P では選択から除外 (toast で通知)
削除Dot を Delete → 接続エッジも削除。接続先ノート削除で孤立した Dot は自動削除

番外: Shape (汎用図形)

shape ディレクトリは円/三角/六角形など装飾図形。Inspector の Shape Picker で選ぶ。Frame と組み合わせて使うことが多い。

ノード種別ピッカー (新規作成)

⌨ Ctrl + Shift + N でピッカー → 矢印選択 → Enter。各種別の最初の英字キーがアクセラレータ (01-canvas-and-gestures › 新規作成 参照)。

ノードのコピー / 貼り付け

操作効果
Ctrl + C選択ノートを内部クリップボードに
Ctrl + Vカーソル位置に貼り付け
Ctrl + Shift + V同位置 (重ねて) 貼り付け
Ctrl + D選択を複製 (右下に少しずらして配置)

外部クリップボード (画像/テキスト) からの貼り付けも:

  • 画像 → Image ノードを生成
  • URL 文字列 → Link ノードを生成 (タイトル auto-fetch)
  • プレーンテキスト → Text ノード
  • Markdown → Markdown ノード

縦書きノートの最小幅制約

縦書きノート (writingMode: vertical-rl/lr) は 1 列ぶんの幅を維持 するため、フォントサイズに応じて 自動的に最小幅が設定 される。手動リサイズで 1 列幅を下回ろうとしても clamp される。

仕組み

計算項目値
基準フォントサイズnode.fontSize ?? 14 (Inspector の Font size)
1 列幅fontSize × 1.5 (line-height + 左右余白を含む)
グローバル下限32 px (MIN_NOTE_WIDTH)
実効最小幅max(1列幅, 32px)

例: フォントサイズ 14 → 21 px と 32 px の大きい方 = 32 px 例: フォントサイズ 24 → 36 px と 32 px の大きい方 = 36 px

適用される操作

  • リサイズハンドル (8 方向) ドラッグ: 最小幅を下回るとそこで止まる (clamp)
  • コーナーリサイズ: 同上
  • Inspector で width を数値入力: 最小幅未満は自動補正
  • 横書きノート: この制約は 適用されない (任意の幅にできる)

内部実装 (参考)

  • app/lib/canvas/min_vertical_note_width.dart で計算ロジック (minVerticalNoteWidth(node), resizeMinWidthForNode(node))
  • app/test/canvas/min_vertical_width_test.dart で 4 ケース (fontSize=14 / 横書き非制約 / drag clamp / corner clamp) を保証

動作確認

  1. 縦書きノートを作成、Inspector で fontSize=14 にする
  2. リサイズハンドルで幅を縮める → 32 px 未満には縮まない
  3. fontSize=24 に変更 → 最小幅が 36 px に上がる。現在 width が 36 未満なら自動で拡張される
  4. 横書きに切り替える → 制約が外れ、任意幅 (1 px 以上) にリサイズ可能
