親子・階層パネル (v0.0.4 O 系)

選択ノートを含む階層全体を ルート祖先から DFS で展開したツリー として表示する。深さ無制限。

要素動作
階層ツリー (N件)ルート祖先から DFS で全子孫を展開、depth × 18px でインデント
各行└─ ツリーガイド + NodeKind 別アイコン (📦 Container / ⬜ Frame / 📝 text 等) + ラベル
◀ マーカー現在選択中のノート、行が背景色強調 + 太字
行クリック (選択中以外)キャンバスでそのノートを選択 (フォーカス移動)
✕ ボタン (ルート以外)その行のノートの親 Edge を 1 本削除、子孫は保持
「このノートの親子関係を解除」選択ノートに接続している hierarchy Edge を全削除 (root もそれ自身を独立化)

利点

  • どの子ノートを選択しても 同じ階層ツリーが表示 される → a-b-c の関係性が一目でわかる
  • 親子関係が深くても (a → b → c → d → e の 5 段以上でも) すべて表示
  • 現在位置 (◀ マーカー + 強調背景) と兄弟関係が一目でわかる

詳細は 05-edges-and-connections.md 参照。Ctrl + P で作成、Alt + P で解除、ノート右クリックメニューからも解除可能。

1. テキスト書式 (Format Panel)

Bold / Italic / Underline / Strikethrough

ボタンキー効果
BCtrl + B太字
_I_Ctrl + I斜体
<u>U</u>Ctrl + U下線
SCtrl + Shift + S取り消し線

選択範囲がある場合は その範囲のみ に適用 (InlineMark)、なければノート全体。

フォントサイズ

スライダー or 数値入力。8〜144 px。既定 14 px。

Ctrl + + / Ctrl + - で 1 段階 (2 px) 増減。

配置

水平: 左 / 中央 / 右 垂直: 上 / 中央 / 下

⌨ Ctrl + L / Ctrl + E / Ctrl + R で水平、Ctrl + Shift + L/E/R で垂直。

Alignment ボタンの writingMode 適応

ノートの writingMode (horizontal-tb / vertical-rl / vertical-lr) と textDirection (ltr / rtl) に応じて、Inspector の Alignment ボタンは アイコンと意味が動的に切り替わる。物理的な「左寄せ」ではなく、論理的な「行頭寄せ / 中央 / 行末寄せ / 両端揃え」が常に正しく表示される設計。

modestart / leftcenterend / rightjustify
横書き LTR (horizontal-tb + ltr)左寄せ ⮜中央 ⮯右寄せ ⮞両端 ⮇
横書き RTL (horizontal-tb + rtl)右寄せ ⮞中央 ⮯左寄せ ⮜両端 ⮇
縦書き (vertical-rl/lr)上寄せ ⮝中央 ⮯下寄せ ⮟(非表示)

縦書きでは justify は意味をなさないため非表示 になる (列単位での両端揃えは未対応)。

内部実装 (参考)

  • app/lib/panels/inspector/format/alignment_button_presentation.dart で mode → icon/tooltip マッピング
  • app/test/panels/inspector/alignment_button_test.dart で 4 ケース (横書き LTR / 横書き RTL / 縦書き / justify 非表示) を保証

動作確認

  1. 横書きノート選択 → Inspector Alignment 4 ボタン (左/中/右/両端) が出る
  2. ノートの writingMode を縦書きに切り替える → Alignment ボタンが上/中/下の 3 ボタンに変わる (justify が消える)
  3. テキスト方向を rtl に変えると左寄せ ⇄ 右寄せのアイコンが入れ替わる

テキスト色

カラーピッカー。プリセット 16 色 + カスタム HEX 入力。Recent 履歴 8 色。

2. 図形 (Shape)

ノートの形を変える。

形状用途
rect (矩形, 既定)標準
rounded角丸 (cornerRadius 調整可)
ellipse楕円
diamondひし形 (フローチャート判定)
hexagon六角形 (タグ・カテゴリ感)
cloud雲形
parallelogram平行四辺形
triangle三角

⌨ Ctrl + Shift + 1〜8 でショートカット (上から順)。

CornerRadius

rounded 選択時に有効。0〜32 px。

3. 枠線 (Border)

プロパティ値
Width0〜10 px (0 で枠なし)
Stylesolid / dashed / dotted / double
Colorカラーピッカー

Ctrl + Shift + B で枠線 ON / OFF (切替)。

4. 塗り (Fill)

ノート内部の色。

プロパティ値
Colorカラーピッカー / 透明 / グラデーション 🚧
Opacity0〜100%

5. エフェクト (Effects)

Drop Shadow

ON / OFF。色・距離・ぼかしは固定 (Settings で全体トーン変更)。

Opacity

ノート全体の不透明度。0% で完全透明 (選択は可)。

Magnetic Snap

ON のとき、ドラッグ移動中に他ノートのエッジと整合する位置で吸着。

⚠ 全ノートで Magnetic ON だと逆に引っかかりすぎる。重要ノートだけ ON 推奨。

6. ノート種別切替 (Kind Switcher)

Inspector 上部のドロップダウン。データを保ったまま種別変換。

例: text → markdown は text を body にコピー。markdown → text は最初の段落を text に。

7. 共通スタイルライブラリ (Style Library) 🚧

styles[] (map.json) に名前付きスタイル定義 → ノートに styleRef で参照。1 か所変えれば全ノートに反映。

現在は手動編集 / API 経由。GUI の Style Manager は 将来予定。

エッジを選択すると Edge セクションが現れる (03-edges-and-connections › エッジのスタイル 参照)。

複数選択時の Inspector

複数ノート選択時は 共通プロパティのみ が表示され、変更すると 全選択ノートに一括適用。

例: 5 個選択 → fontSize を 18 に → 全部 18 になる。
