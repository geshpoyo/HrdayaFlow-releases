12 Planner / Calendar / Task list

← 11 ファイル | 目次 | → 13 テーマ

Planner は、マインドマップとは別に日程・タスクを扱う作業面です。左アクティビティバーの プランナー から開きます。上部のセグメントで Timeline / Task list / Calendar を切り替えます（最後に使ったタブは再起動後も復元されます）。Timeline は後フェーズです。

データの考え方

Planner の予定・タスクは、.hrf ファイルではなくアプリ全体の Planner store に保存されます。A.hrf で登録した予定は、B.hrf を開いていても同じ Planner から見えます。

永続先はアプリサポートフォルダ配下の hrdayaflow/planner.json（version: 2）です。v1 のファイルを開くと Inbox を自動生成し、同ディレクトリに planner.v1.bak.json を一度だけ残してから v2 で保存します（ダウングレード不可）。将来 SQLite へ移行できるよう、UI と保存層は分離されています。

タスクと予定は同じデータ型（CalItem）で、種別（kind）だけで分かれます。Task list で編集・完了した内容は Calendar にもすぐ反映されます。

Task list

受信トレイ / 今日 / 次の 7 日間 / リスト別のタスク一覧です。

左ナビ

項目内容
受信トレイリスト未指定（または Inbox）の未完了タスク
今日期限・開始が今日のもの ＋ 期限超過
次の 7 日間今日〜今日+6 日 ＋ 期限超過
リスト一覧色ドット・名前・未完了件数。「+ リスト」で新規作成
完了済み完了 / 実行しない（内部ステータス）の履歴

クイック追加

上部の入力欄に自然文を入れて Enter。例:

明日 15時 会議
毎週月 9時 朝会
6/20 締切
毎日 朝ラン

常に タスク として追加されます。リスト別ビューではそのリストへ、それ以外は受信トレイへ入ります。今日 / 次の 7 日間ビューで日付が無い入力には、今日の日付が補完されます。

行の操作

操作効果
チェック完了。繰り返し（RRULE）付きは 次回日付へロール（SnackBar で案内）
行タップ編集ダイアログ（リスト選択可）
同一セクション内ドラッグ並び順を保存（再起動後も維持）
↑↓ / Space / Enter / Ctrl+N行フォーカス・完了トグル・編集・入力欄へ

リストの管理

「+ リスト」またはリストの編集から、名前 / 色（テーマ色または任意 hex）/ 絵文字を設定できます。受信トレイは削除・改名不可。リスト削除時は所属タスクが受信トレイへ移ります（確認あり）。

Calendar ビュー

Calendar は月 / 週 / 日を切り替えられます。

表示用途
月月全体の予定量を俯瞰する
週時間帯つきの予定を並べて見る
日1 日の予定を詳細に見る

上部のナビゲーションで前後へ移動し、今日で現在日に戻ります。色はリスト色 → 優先度 → 種別の順で決まります（テーマトークン経由）。

予定・タスクの追加（Calendar）

Calendar 上の日付や時間帯をクリックすると追加ダイアログが開きます。予定は開始 / 終了、終日、タスクは期限や完了状態・所属リストを持てます。

下部のクイック追加バーでも日本語・英語の自然な入力を簡易解析します（Calendar 側は予定/タスクを入力から推定）。

対応する主な解析:

入力解釈
今日 / 明日 / 明後日 / 昨日相対日付
月火水木金土日 / mon tue ...曜日
14:00 / 9時30分時刻
毎日 / 毎週 / 平日 / 毎月D日RRULE 繰り返し

繰り返しと完了ロール

繰り返しは RFC5545 の RRULE 文字列として保存されます（daily / weekly / monthly / yearly の基本形と曜日・月日指定）。

Task list でも Calendar でも、完了トグルは同じ経路です。

  • RRULE なし → 完了
  • RRULE あり → 次の occurrence へ due/start/end を進め、未完了のまま（COUNT/UNTIL 到達時は通常完了）

Quick Entry（トレイ）のタスクモード

ウィンドウを閉じたあともトレイから Quick Entry を開けます。ダイアログ上部で ノート | タスク を切り替えられます（最後のモードを記憶）。

  • ノート: 従来どおり、対象マップへノート追加
  • タスク: 入力を自然文解析して受信トレイにタスク追加（プランナーと同じパーサ）

MCP ツール（planner）

アプリ内蔵 MCP（既定 localhost:3737）から、マインドマップモード中でもタスク操作できます。

ツール用途
list_task_listsリスト一覧（Inbox・未完了件数付き）
list_tasksview: inbox / today / next7 / list / completed（listId・limit 任意）
add_tasktext（自然文）または title + 任意フィールド。kind は task 固定
complete_taskid で完了。undo: true で未完了に戻す。ロール結果を返す

例: add_task（text: "明日 15時 会議"）→ list_tasks（view: today）→ complete_task。

マップ系ツールの概要は 開発者ガイド も参照。

マインドマップとの関係

現段階では Planner はアプリ全体の予定表として独立しています。今後、ノートから予定化、予定から元ノートへジャンプ、Kanban / Gantt / Table との同一データ表示へ拡張する計画があります（タスク管理ロードマップ T2 以降）。

カレンダーの表示切替

カレンダー上部のセグメントボタンで 月 / 週 / 日 を切り替えます。

表示向いていること
月全体の埋まり具合を見る
週その週の配分を見る
日1 日の中の時間割を詰める

優先度

予定とタスクには優先度を付けられます。なし / 低 / 中 / 高 の 4 段階です。
スマートリストの並び順に効きます。
