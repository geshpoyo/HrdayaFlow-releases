12 Planner / Calendar

← 11 ファイル | 目次 | → 13 テーマ

Planner は、マインドマップとは別に日程・タスクを扱う作業面です。左アクティビティバーの プランナー から開きます。

現在の主実装は Calendar です。Timeline / Task list は画面枠がありますが、後フェーズで拡張予定です。

データの考え方

Planner の予定・タスクは、.hrf ファイルではなくアプリ全体の Planner store に保存されます。A.hrf で登録した予定は、B.hrf を開いていても同じ Planner から見えます。

永続先はアプリサポートフォルダ配下の hrdayaflow/planner.json です。将来 SQLite へ移行できるよう、UI と保存層は分離されています。

Calendar ビュー

Calendar は月 / 週 / 日を切り替えられます。

表示用途
月月全体の予定量を俯瞰する
週時間帯つきの予定を並べて見る
日1 日の予定を詳細に見る

上部のナビゲーションで前後へ移動し、今日で現在日に戻ります。

予定・タスクの追加

Calendar 上の日付や時間帯をクリックすると追加ダイアログが開きます。予定は開始 / 終了、終日、タスクは期限や完了状態を持てます。

下部のクイック追加バーでは、日本語・英語の自然な入力を簡易解析します。

例:

明日 14:00 打ち合わせ
毎週月 9:00 週次レビュー
平日 8:30 朝の確認
monthly 15 report

対応する主な解析:

入力解釈
今日 / 明日 / 明後日 / 昨日相対日付
月火水木金土日 / mon tue ...曜日
14:00 / 9時30分時刻
毎日 / 毎週 / 平日 / 毎月D日RRULE 繰り返し

繰り返し

繰り返しは RFC5545 の RRULE 文字列として保存されます。現在は daily / weekly / monthly / yearly の基本形と、曜日・月日指定を扱います。

操作

操作効果
予定クリック編集ダイアログを開く
タスクのチェック完了 / 未完了を切り替え
週 / 日ビューでドラッグ予定の移動
下端リサイズ予定の終了時刻を変更

マインドマップとの関係

現段階では Planner はアプリ全体の予定表として独立しています。今後、ノートから予定化、予定から元ノートへジャンプ、Kanban / Gantt / Table との同一データ表示へ拡張する計画があります。
