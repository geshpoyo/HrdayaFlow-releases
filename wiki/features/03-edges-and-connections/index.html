05 エッジと接続

← 04 ノード | 目次 | → 06 グループ

ノート同士を関係づけるのがエッジ。ただの線ではなく、意味 (semantic type) と 見た目 (style) を独立して扱う。

エッジを引く

🖱 ノードの上端 / 右端 / 下端 / 左端にホバー → 接続ハンドル (小さな○) が出る → ハンドルをドラッグ → 行き先ノードへドロップ。

修飾キー生成されるエッジ
なしparent-child (シンプル線)
Shift + ドラッグcause-effect (矢印つき)
Alt + ドラッグ逆向き矢印
Ctrl + ドラッグ双方向矢印
Shift + Alt + ドラッグdependency (破線矢印)

キーボード

⌨ Ctrl + P (Mac は ⌘ + P): 選択ノートに親子 (階層) Edge を追加します。

  • アクティブオブジェクト (= 最後に選んだノート、太い実線ボーダーで表示) が 親、それ以外の選択ノートすべてが 子 になります (Blender 流 "Make Parent")
  • 3 ノート以上選択していると、アクティブ 1 つを親に、他全部を子にする「放射状」の親子関係が一括作成されます
  • 子が既に別の親を持っている場合は silent replacement で上書きされます (1 子 1 親の原則)
  • 多重選択で cycle / self-parent が含まれる場合は partial success: 該当ペアだけスキップして残りを作成、結果は toast で通知

⌨ Alt + P: 選択ノートそれぞれの 親 hierarchy Edge を 1 本削除します (Blender 流 "Clear Parent")。子孫との関係は保持されます。

🖱 ノート右クリック → 「親子関係を解除」: Alt+P と同じ挙動。選択中ノートに親がある時のみメニューに現れます。

親子関係の特殊な振る舞い (v0.0.4 O 系)

  • キャンバスには矢印が描画されません (EdgeKind.hierarchy は描画されない)
  • データは Inspector「親子・階層」セクションで ルートからの完全ツリー として確認・編集できます
  • 親を移動すると子孫すべてが推移的に追従 します (Blender 流 transform inheritance)
    • 対象操作: G (Blender grab) / D&D ドラッグ / 矢印キー nudge / Inspector x,y 入力
    • 回転 (R) / スケール (S) の伝播は v2 以降
  • Container と Frame も親子関係 Edge の端点 になれます
    • Container を移動すると中の子孫が追従 (Container.containerMembers[] は cache)
    • Frame に対しても親子関係を結べる (装飾フレームに子ノートを従属させる)
  • 親子関係と通常エッジは共存できます: 親 a → 子 b の親子関係を持つノート間に、generic / causality / reference 等の通常エッジを別途引くことが可能。両者は独立したレイヤーとして扱われる

エッジには「意味」を持たせられます。見た目とは独立したデータで、.hrf に保存されます。
インスペクタの「接続」で切り替えます。9 種類あります。

エッジのアニメーション（LFO）

エッジは動かせます。インスペクタのアニメーション節で設定します。

項目選べる値
波形サイン / 三角 / 鋸歯 / 逆鋸 / 矩形 / S&H
対象不透明度 / 流れ / 脈動 / グロー
向き順方向 / 逆方向 / 両方 / 継承
再生条件常時 / ホバー時 / 選択時 / オフ / 継承

「流れ」は破線が線に沿って動く表現で、工程やデータの向きを示すのに向いています。
「ホバー時」にしておくと普段は静止するので、マップ全体が騒がしくなりません。

⚙ プレゼンテーションモードでは、アニメーションを一時停止できます。
同時に動くエッジの本数にも上限があり、大きなマップでも重くなりません。

接続点 (Pin)

ノートには複数の 接続点 (上下左右の中央に既定で 4 つ) がある。エッジの from / to は {nodeId, pin} の組として保存される。

🚧 任意位置への pin 追加は将来予定。現状は 4 方向固定。

自動レイアウトとエッジ

04-groups-and-containers の Container 内で「Auto Layout」を実行すると、エッジを最短にする配置を計算 (Reingold-Tilford 風)。

既存ノートの繋ぎ替え

🖱 エッジの 端点 (○) をドラッグ → 別ノードに重ねる → 接続が変わる。

多対多

1 つのノートから何本でも引ける。ノートに来るエッジ数も無制限。Inspector の「接続一覧」で全部見える。

接続検証 (G/S/R 変形時)

K-gsr10 (2026-04 修正) で、Group/Scale/Rotate 変形時にエッジが自動で追従。回転 90° でもエッジ端が自然に繋がる。

エッジの一括操作

複数選択 → 右クリック → エッジ操作 メニュー:

  • 一括スタイル変更 (色 / 線幅)
  • 一括 type 変更
  • 削除

エッジ非表示

Layer (Outline パネル) でレイヤー単位で表示/非表示。エッジだけのレイヤーを作って、複雑なマップを段階的に見せられる。

ナイフでエッジリルート (Dot 中継)

エッジが多くて混雑したキャンバスでは、ナイフツールで複数エッジを切って Dot という中継ノートを生成し、視覚的に集約できる。Blender Node Wrangler のナイフツールを参考にしている。

切断前 → 切断後 (イメージ)

切断前 (ファンイン):
  A ──→ X
  B ──→ X
  C ──→ X

切断後 (1 ストローク = 1 Dot):
  A ──→ ● ──→ X
  B ──┘    └── (Dot→X は本数ぶん残る。重なって 1 本に見えることもある)
  C ──┘

スクリーンショット付きの設計資料: HrdayaFlow/docs/v0-0-4/q-knife-reroute/README.md（開発リポジトリ）

操作

  1. Shift を押しながら 右マウスダウン → ドラッグ で軌跡を引く
  2. 軌跡が通過した 通常エッジ (キャンバスに見えるエッジ) が赤くハイライトされる
  3. 右マウスアップで切断確定。ストローク終点に Dot が 1 個生成される
  4. 切断された各エッジ S → T は S → Dot と Dot → T の 2 本に分割される

仕様

  • 1 ストローク = 1 Dot: ストロークで切った全エッジは同じ Dot を共有する (自動集約)
  • 属性継承: 元エッジの矢印頭・色・線種などは分割後の両方に継承される
  • Target merge なし: 同じ Target に複数エッジが向かっていても自動でまとめない。Dot → Target が N 本残る (視覚的には重なって 1 本に見えることもある)
  • Hierarchy Edge は切れない: 親子関係を表す内部エッジはナイフ通過しても無視される (親子関係 参照)
  • Undo: 1 ストローク = 1 Undo (Ctrl + Z 1 回でストローク全体を巻き戻す)

中断 / 誤発動防止

  • ドラッグ中の Esc で軌跡破棄。Edge も Dot も変化しない
  • Shift + 右クリック (移動 3 px 未満で離す) は通常の右クリックメニューを表示する (ナイフは発動しない)

Dot ノートについて

Dot の種別・移動・サイズの詳細は ノート種別 Dot を参照。

  • 見た目: 小さい ● (塗り潰し円)。初期直径 14 px
  • 移動: 通常ノートと同じく G / ドラッグ / 矢印キー (1 px / Shift 16 px / Ctrl 64 px)
  • サイズ変更: S 又は 8 方向リサイズハンドル (常に正方形 = 円、4–48 px)
  • 回転: 円なので意味なし。R は無効
  • テキスト編集 / F2: 無効 (ラベルを持たない)
  • Ctrl+P (親子化): 無効 (Dot は親子関係に含められない)
  • 自動削除: Dot に接続するエッジが 0 本になると Dot 自身も自動削除される (ゴミ Dot 散乱防止)
  • Ctrl+G: Dot を Container メンバーにできる (Container 移動で追従)

ルーティング（経路の決め方）

エッジをどう引き回すかは 2 つの設定で決まります。表示メニューから切り替えます。

設定既定何が変わるか
グローバル束線ルーティングON同じ方向へ向かうエッジを 3 層のレーンに束ねて通す。密な図でも線が重なりにくい。OFF にすると従来どおり 1 本ずつ独立に経路を決める
エッジスマートルーティングOFFノートを避けて回り込む経路を計算する。既存の .hrf と見た目を変えないため既定は OFF

束線が有効なとき、次の値で見え方を調整できます。

項目既定意味
レーン間隔12 px束ねた線どうしの間隔
通路の最小幅8 pxこれより狭い隙間には通さない
曲がりの半径6 px角の丸み

⚠ 重なったノートの隙間には通しません。 重なり合うノートの外接矩形をひとつにまとめて
障害物として扱うため、見た目の細い隙間を線がすり抜けることはありません。

🖱 ルーティングを切り替えると既存エッジの経路が変わります。選択中のエッジは、
経路が動いても選択が外れないように救済されます。
