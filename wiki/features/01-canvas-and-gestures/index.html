03 キャンバスとジェスチャー

← 02 はじめに | 目次 | → 04 ノード

キャンバスは無限平面です。ノードを置く場所を気にせず、思考を広げていくのが思想。

左アクティビティバー

画面左端にはモード切替用のアクティビティバーがあります。

項目動作
マップ通常のマインドマップキャンバスを表示
プランナーCalendar / Timeline / Task list を扱う Planner 画面を表示
折りたたみボタンラベルを隠し、アイコンだけの細いレールに切り替え

折りたたみ状態は保存され、次回起動時にも維持されます。キャンバスを広く使いたいときは折りたたみ、モード名を確認したいときだけ展開します。

移動 (パン)

操作効果
🖱 中ボタンドラッグパン
🖱 スペース + 左ボタンドラッグパン (ノートエディット中に便利)
🖱 タッチパッド 2 本指スワイプパン
⌨ 矢印キー16 px ずつパン
⌨ Shift + 矢印128 px ずつパン

ズーム

操作効果
🖱 Ctrl + マウスホイールカーソル位置を中心にズーム
🖱 タッチパッド ピンチズーム
⌨ Ctrl + = (または Ctrl + ;)ズーム +
⌨ Ctrl + -ズーム −
⌨ Ctrl + 0100% に戻す
⌨ Ctrl + 9キャンバス全体が見えるように Fit
⌨ Ctrl + 8最小ズーム (5%)

ズーム範囲: 5% 〜 800%。ステータスバーに現在のズーム率が表示されます。

選択

単一選択

🖱 ノード本体をクリック → そのノードが選択 (青いハロー)。

複数選択

操作効果
🖱 Shift + クリック選択に追加 / 解除
🖱 Ctrl + クリック同上 (Shift と同義)
🖱 空白からドラッグ (矩形)矩形に 完全に含まれる ノードを選択
🖱 Alt + 矩形ドラッグ矩形に 触れる ノードを選択 (Crossing)
🖱 投げ縄 (Shift + 矩形ドラッグ 開始時に円弧)自由形状で選択 🚧
⌨ Ctrl + A全選択
⌨ Ctrl + Shift + A選択反転
⌨ Esc選択解除

🖱 矩形 / Crossing / 投げ縄 の挙動は CAD / Photoshop の慣例に倣う。

操作効果
🖱 Shift + 右マウスドラッグナイフでエッジ切断 → Dot リルート ([[03-edges-and-connections#ナイフでエッジリルート-dot-中継\詳細]])

ノートの幾何アライン（Pie、NA-01）

複数ノートを選んだ状態で ⌥ A（Windows は Alt+A） を押すと、カーソル付近に Pie メニューが開きます（基準は 最後に選んだノート＝アクティブ。アクティブは動きません）。

  • 確定: 目的の方向にマウスを動かしたあと Alt を離す（中心のデッドゾーンのまま離すとキャンセル）
  • キャンセル: Esc
  • 中身: 上下左右の Sides 揃え、水平／垂直センター、水平／垂直ディストリビュート（3 ノート以上）
  • 接続線の Edge や枠線の Border とは別物です（用語の混同に注意）

選択が 1 件だけのときはトーストで案内のみです。ノートを編集中はショートカットは効きません。

種別フィルタ選択 🚧

将来的に「Image ノードだけ全選択」が Outline パネルから可能になる予定。

新規作成

ノート

🖱 キャンバス空白を ダブルクリック → 空のテキストノードが作られ、即編集モードへ。

種別を指定して新規

⌨ Ctrl + Shift + N → ノード種別ピッカーが開く → 矢印で選択 → Enter

キー種別
Ttext
Mmarkdown
Iimage
Llink
Vvideo
Aaudio
Kchecklist
Ccode
Eembed
Xmath
Fframe
Gcontainer

既存ノードから派生

選択ノード上で ⌨ Tab → 子ノードを右側に作成、エッジで接続。

編集モードと選択モードの行き来

モード入る出る
編集モード (テキスト入力)ノートをダブルクリック / F2 / Enter (選択中)Esc / 別所をクリック
選択モード (移動・整列)ノートを 1 度クリックEsc で選択解除

⚠ 編集モード中は Tab / Shift+Tab / 矢印キーがエディタに食われる。Esc で抜けてからショートカット使用。

グリッドとスナップ

グリッド

⌨ Ctrl + ; で表示 / 非表示。

設定:

  • グリッド単位: 8 / 16 / 32 / 64 px から選択 (Settings)
  • 既定: 16 px
  • スナップは ON でも、グリッド非表示 OK

スナップ

⌨ Shift + ; で ON / OFF。

種類効果
グリッドスナップ移動先がグリッド線にスナップ
エッジスナップ (Magnetic)他ノードの辺と整合する位置に吸着 — 06-inspector-and-formatting › magnetic
ガイド線スナップ既存ノートと中心 / 上端 / 下端を揃えると赤い補助線が出る

一時的にスナップ無効にしたいときは Alt を押しながらドラッグ。

移動・整列

移動

🖱 ノートをドラッグ → 新位置へ。複数選択時は 全部まとめて移動。

⌨ 矢印キー で 1 px / Shift + 矢印 で 16 px / Ctrl + 矢印 で 64 px 移動。

整列 (Align)

複数選択して右クリック → 整列 → 選択肢:

操作効果
左揃え / 中央揃え / 右揃えX 軸
上揃え / 中央揃え / 下揃えY 軸
横方向均等配置X 間隔を平均化
縦方向均等配置Y 間隔を平均化

重ね順 (Z-order)

操作効果
⌨ Ctrl + ]1 段上へ
⌨ Ctrl + [1 段下へ
⌨ Ctrl + Shift + ]最前面
⌨ Ctrl + Shift + [最背面

変形 (Blender 風 G/S/R)

選択中に ⌨ G / S / R を押すと変形モード。マウス移動 → クリックで確定 / Esc でキャンセル。

キーモード軸固定
GGrab (移動)X / Y で軸固定
SScale (拡大縮小)X / Y で軸固定、数値タイプで倍率指定
RRotate (回転)数値タイプで角度指定 (度)

🚧 Scale / Rotate は K-gsr10 (2026-04 修正) で安定化。複数ノードを群として変形。

エッジ作成

🖱 ノードの上端/右端/下端/左端にホバー → 接続ハンドル が出る → ドラッグで他のノードへ → エッジ生成。

修飾エッジ種別
無単純な線 (parent-child)
Shift順序つき (cause-effect / arrow with arrowhead)
Alt逆向き
Ctrl双方向 (両端矢印)

詳細は 03-edges-and-connections。

中央に戻る

操作効果
⌨ Ctrl + 9全マップが収まるように zoom & 中心合わせ
⌨ Home原点 (0,0) にジャンプ
⌨ Endマップの中心 (重心) にジャンプ
