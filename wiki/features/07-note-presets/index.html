07-note-presets

ノートプリセット (NP-01)

よく使うノートの見た目（フォント、色、枠、サイズなど）を プリセット として保存し、ワンクリックで適用できます。アプリ全体用と、開いている .hrf 専用のプリセットを分けて持てます。

関連

  • フォーマット全般: 06-formatting（存在する場合）
  • キャンバス操作: 01-canvas-and-gestures

プリセットの作成

  1. スタイルの元にしたい ノートを 1 つ選択 します。
  2. インスペクタ上部の プリセット セクションで ＋ を押します（選択が 0 件のときは無効）。
  3. ダイアログで名前・保存先（★デフォルト / HrdayaFlow / プロジェクト）・各項目の適用 ON/OFF を設定して 保存。

空の初期値から作る場合も、同じダイアログで項目ごとにチェックと値を入れます。

適用とデフォルト

  • 行をクリック（☆・🔐・✏️ 以外）で、選択中のノートに即適用します。Undo で戻せます。
  • ☆ / ★ で「新規ノート作成時に自動適用するデフォルト」を切り替えます。
  • 複数選択 時は一括適用（ホバープレビューはしません）。

🔐 ロック

ロック中は ✏️ 編集 と 🗑️ 削除 が無効です。🔐 を押すと 約 5 秒だけ 解除され、その間に編集・削除できます。

スタイルのコピー／貼り付け

  1. コピー元ノートを Ctrl+C（Mac は Cmd+C）でコピーします。
  2. 貼り付け先ノートを選び Ctrl+Shift+V（Mac は Cmd+Shift+V）を押します。
  3. チップで項目を選び 適用。次回起動まで選択が記憶されます。

折りたたみ

「HrdayaFlow プリセット」「プロジェクト (.hrf)」セクションの見出しをタップすると折りたたみできます。状態はアプリに保存されます。
