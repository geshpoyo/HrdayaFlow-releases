05-note-stacks

ノート Stack (NS-01)

複数選択したノートを、最後に選択した（アクティブ）ノートを固定し、残りをその 右（横） または 下（縦） に隙間を空けて並べます。整列ガイド（Align）とは別機能です。

関連

  • キャンバス全般: 01-canvas-and-gestures
  • ノートプリセット: 07-note-presets

使い方

  1. Shift+クリック などで 2 つ以上 ノートを選ぶ（最後に選んだノートが親）。
  2. 次のいずれかで実行:
    • ツールバーの Stack アイコンをクリックするか、長押し / 右クリックでサブメニュー（縦・横・解除）。
    • インスペクタの Stack セクションで方向を選んで Stack 整列。
    • 右クリックメニューから Stack（縦 / 横）。
    • 編集 > Stack サブメニュー。
  3. 軸は 縦 か 横 のいずれかを選びます（保存済みマップの既存 Stack はそのまま開けます）。

ショートカット

ノートを テキスト編集中にしていない ときのみ有効です。

操作キー
Stack（縦）Ctrl+Alt+V（Mac は Cmd+Alt+V）
Stack（横）Ctrl+Alt+H（Mac は Cmd+Alt+H）

別名保存は Ctrl+Alt+S（Mac は Cmd+Alt+S）です。
クリップボードからのインポートは Ctrl+Shift+Alt+V（Mac は Cmd+Shift+Alt+V）です。

インスペクタ（Stack 状態のとき）

同一 Stack に属するノートだけをまとめて選ぶと:

  • Alignment（先頭 / 中央 / 末尾 / 両端）を変えて即再整列できます。連続操作は Undo が 1 まとまりになります。
  • Margin スライダーで子どうしの間隔を変えられます。ドラッグ中は Undo が coalesce されます。
  • Stack 解除で stackGroupId などの状態を消します。

単一選択時でも Stack セクションは表示されますが、Stack 整列は 2 件以上選んだときだけ有効です。

永続化

Stack の状態は map.json 上の各ノードに保存されます。.hrf を保存して再度開くと復元されます。フィールドがない古いファイルもそのまま開けます。

親ノートを削除したとき

同一 Stack に子が残り、削除されたのが親だけだった場合、もっとも先頭側にあった子が新しい親になります（グループは維持）。

並べ方（寄せ）

スタックに入れたノートの揃え方を選べます。

寄せ結果
先頭寄せ上（横並びなら左）に揃える
中央中心線に揃える
末尾寄せ下（横並びなら右）に揃える
均等端から端まで等間隔に配置する

「均等」だけは間隔が中身の数で変わります。他の 3 つは間隔を保ったまま位置だけ動かします。
