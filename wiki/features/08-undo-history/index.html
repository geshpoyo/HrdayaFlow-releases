08 Undo / 履歴

← 07 Inspector | 目次 | → 09 検索

「やり直し」は K11-bis (2026-05) で JSON Patch (RFC 6902) ベースの差分履歴に刷新。1000+ ノードのマップでも履歴 1 件あたりミリ秒オーダー。

基本操作

操作効果
⌨ Ctrl + Z1 つ前の状態に戻す (Undo)
⌨ Ctrl + Y または Ctrl + Shift + Zやり直し (Redo)
⌨ Ctrl + Alt + Z履歴ビューアを開く

⚠ 編集モード中の Ctrl + Z は テキストエディタ内の Undo に行く。Esc でキャンバスに戻ってから。

仕組み: JSON Patch ベース

各 mutation (操作) は次の流れで保存される:

mutation 開始 → before snapshot (map.json)
              → 操作実行 → after snapshot
              → diff(before, after) で JSON Patch 生成
              → 履歴スタックに push
利点効果
軽量数 KB / 履歴 (大きなマップでも)
可搬.hrf の history/snapshots/ にも書ける
検査可履歴ビューアで何が変わったか見える
部分適用「色だけ戻す」「位置だけ戻す」の選択 Undo 🚧

実装: app/lib/undo/canvas_undo_adapter.dart + core/Cargo.toml の json-patch crate。

Coalesce (連続操作のマージ)

ノートをドラッグして 60 フレーム動かすと、履歴に 60 件入ってしまうのを防ぐため、同じ key の連続操作は 1 件にまとめられる。

_beforeMutation('move-node', coalesceKey: 'node_drag:${nodeId}')
操作coalesceKeyまとめ単位
ノート移動node_drag:<id>同一ノード 1 件
ノートリサイズnode_resize:<id>同一ノード 1 件
テキスト編集text_edit:<id>500 ms 無入力で確定
Inspector スライダーinspector:<prop>:<id>スライダー離すまで 1 件

「Undo 1 回で 1 ドラッグ全部戻る」というユーザー期待に合わせる。

履歴ビューア (Time Machine)

⌨ Ctrl + Alt + Z で開く。

┌── 履歴 ────────────────────────┐
│ ● 18:32:11  ノート追加 "メモ"   │ ← 現在
│ ● 18:32:05  色変更 (3 件)      │
│ ● 18:31:58  ドラッグ移動        │
│ ● 18:31:50  Container 化        │
│ ● 18:30:42  ファイル開く         │ ← 起点
└───────────────────────────────┘
操作効果
行クリックその時点の状態にジャンプ (前後 Undo / Redo を一気に)
行右クリック → 「ここから分岐」履歴を分岐 (Blender 風) 🚧
行右クリック → 「この差分を見る」JSON Patch 内容を表示
Backspace履歴を 1 件削除 (Redo 不可)

履歴の永続化

既定では メモリ内のみ (アプリ終了で消える)。Settings で「履歴を .hrf に書き出す」を ON にすると:

  • .hrf/history/snapshots/<epoch>.json に保存
  • 次回オープン時に再構築
  • ファイルサイズ増加 (1000 操作で +50 MB 程度)

履歴の上限

既定 500 件。Settings で 100〜10000 に変更可。上限超過時は古いものから捨てる (FIFO)。

Coalesce 設計の勘所

パターン良い coalesce悪い coalesce
同一プロパティの連続変更✅ まとめる—
異なるノートの操作—⚠ 別途扱い
構造変更 (Container 化など)—⚠ まとめない (取り返しがつかない)

詳細実装は docs/may-2026/k11-bis-undo-diff.md 参照。

やり直しできない操作

操作理由
ファイル保存 (Ctrl+S)OS への書き出し
エクスポート (PDF など)OS への書き出し
アプリ起動 / 終了プロセス境界
AI 生成のキャンセルリクエスト送信済

⚠ 大量の構造変更 (例: 「全ノート削除」) は確認ダイアログが出る。Undo はできるが、ヒヤリハットを減らす。

動作確認チェックリスト

  • [ ] ノート追加 → Ctrl + Z で消える
  • [ ] Ctrl + Y で復活
  • [ ] ドラッグ移動 → Ctrl + Z 1 回でドラッグ前に戻る (60 件分が 1 件)
  • [ ] テキスト編集 → 500 ms 無入力後に履歴に 1 件
  • [ ] Ctrl + Alt + Z で履歴ビューア表示
  • [ ] 行クリックで状態ジャンプ
  • [ ] 履歴件数が 500 を超えると古いものが消える
  • [ ] アプリ再起動で履歴が消える (永続化 OFF 時)
  • [ ] 永続化 ON で .hrf 開き直しても履歴が残る
