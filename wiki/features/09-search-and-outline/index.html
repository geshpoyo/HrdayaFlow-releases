09 検索と Outline

← 08 Undo | 目次 | → 10 AI

ノート数が増えても迷わないための、横断的な検索 / 階層ビュー / コマンドパレット。

Outline パネル (左)

ドキュメント全体の階層を見える化。ファイラ風。

▼ ルート (mymap.hrf)
  ▼ 📦 営業部メモ (Container)
    📝 顧客 A
    📝 顧客 B
    🖼 名刺画像
  ▼ 📦 開発メモ
    💾 コード片 (rust)
    🔗 Issue #123
  📝 単独メモ
操作効果
🖱 アイテムクリックキャンバス側でその位置にジャンプ + 選択
🖱 ダブルクリックキャンバスで編集モード
🖱 右クリックコンテキストメニュー (削除・複製・移動など)
▶ / ▼Container 展開 / 折りたたみ
🖱 D&D階層を変える (別 Container に移動)

Layer タブ

Outline 上部に「Layer」リスト。各レイヤー:

  • ☑ 表示 / 非表示
  • 🔒 ロック / アンロック
  • 色付け

Filter タブ

種別・色・タグでフィルタ。例: 「Image ノートのみ」「赤色のみ」「未読 (Tag: todo) のみ」。

⚠ 現状フィルタは限定的。将来的にはタグ完全対応予定。

検索ボックス (Outline 内)

Outline パネルの上部にも検索欄。タイプすると Outline がリアルタイム filter。

Quick Search (Ctrl + F)

キャンバス全体を横断検索。

┌─ 検索 ────────────────────┐
│ 🔍 [          ] [▼ 種別] │
│   [Aa 大小区別] [.* 正規] │
│ ─────────────────────── │
│ 12 件ヒット                │
│   📝 顧客 A の住所          │
│   📝 顧客 B の住所          │
│   ...                      │
└──────────────────────────┘
操作効果
⌨ Enter次のヒットへジャンプ
⌨ Shift + Enter前のヒットへ (ノート編集中の改行とは別動作)
⌨ Esc検索閉じる
⌨ Ctrl + F (再押下)フォーカスを検索欄に戻す

検索オプション

オプション効果
大小区別 (Aa)OFF で case-insensitive
正規表現 (.*)regex 入力モード
種別フィルタtext / markdown / image / ... 限定
Container 内も折りたたまれた中身も対象 (既定 ON)

検索対象

  • ノート本文 (text / markdown / code / checklist items)
  • ノートラベル (Container.label / Frame.label)
  • メタ (originName / alt)
  • ❌ 画像内 OCR は対象外

Command Palette (Ctrl + K)

VS Code 風のコマンド検索。すべての操作を文字で打って実行。

┌─ コマンド ────────────────────┐
│ > エクス_                      │
│ ─────────────────────────── │
│ ⚡ エクスポート: PDF...         │
│ ⚡ エクスポート: Markdown...    │
│ ⚡ エクスポート: Mermaid...     │
│ ⚙ 設定: エクスポート既定先     │
└──────────────────────────────┘
⌨効果
↑ / ↓候補移動
Enter実行
Esc閉じる

候補に出るもの

  • メニュー全項目 (ファイル / 編集 / 表示 / エクスポート / ヘルプ)
  • パネル開閉 (Outline / Inspector / 検索 / AI)
  • 設定項目 (テーマ切替 / 言語切替 / ...)
  • スニペット 🚧 (頻繁に使うパターンを呼び出し)

QuickOpen (ファイル / マップ切替)

⌨ Ctrl + P:

┌─ ファイルを開く ──────────────┐
│ > ten_                        │
│ ─────────────────────────── │
│ 📄 顧客テンプレ.hrf            │
│ 📄 開発テンプレ.hrf            │
│ ─────────────────────────── │
│ 📦 サブマップ: 営業部          │
└──────────────────────────────┘

最近開いたファイル + 開いているサブマップが候補。

Mini Map (オーバービュー)

🚧 検討中。キャンバス全体を縮小表示し、ドラッグで一気に移動。Photoshop / Figma 風。

ジャンプ系ショートカット

⌨効果
Ctrl + 9Fit (全体表示)
Ctrl + 0Zoom 100%
Home原点 (0,0)
Endマップ重心
Ctrl + G (検索ヒット中)次ヒット
Ctrl + Shift + G前ヒット
