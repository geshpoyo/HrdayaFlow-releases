12 テーマ・多言語・アクセシビリティ

← 11 ファイル | 目次 | → 13 ショートカット

見やすく・誰にでも使える・どの言語の人にも使える、を支える章。

テーマ

ライト / ダーク / システム連動

設定 → 表示 → テーマ:

値動作
Light常に明るい
Dark常に暗い
SystemOS 設定に追従 (既定)

⌨ Ctrl + Shift + T で Light / Dark トグル。

カラーアクセント

主アクセント色 (ボタン・選択枠) を選べる:

  • Mandala Gold (既定) — #C8A14C
  • Indigo / Teal / Coral / Forest / Plum

カスタム HEX も入力可。Settings で変更。

フォント

カテゴリ既定カスタマイズ
UINoto Sans JPシステムフォント / カスタム
本文 (text/markdown)Noto Sans JP同上
コード (code)JetBrains Mono同上
数式 (math)Latin Modern(固定)

設定 → 表示 → フォント。サイズはノート単位で Inspector からも変更 (06-inspector-and-formatting)。

キャンバス背景

  • 単色 (既定: テーマ連動)
  • グラデーション
  • パターン (グリッド / ドット / 罫線)
  • 画像 (背景画像)

設定 → 表示 → キャンバス背景。

多言語 (i18n)

サポート言語

言語状態ARB ファイル
日本語 (ja)✅ メインapp/lib/l10n/app_ja.arb
英語 (en)✅app/lib/l10n/app_en.arb

現在この 2 言語だけです。 中国語・韓国語の翻訳ファイルは存在しません。

切り替え

設定 ▸ 言語 で 「OS 設定に従う」/「日本語」/「English」 の 3 択。

切り替えると その場でほとんどの表示が変わります。ただしダイアログや一部の画面は
生成済みのため古い言語のまま残ることがあり、アプリはその場で
「言語を切り替えました。ダイアログや一部画面に反映するにはアプリの再起動を推奨します」
と案内します。再起動は必須ではありません。

翻訳に貢献するには

app/lib/l10n/ 下の ARB ファイルをコピーして翻訳 → PR。詳細は 04-developer-guide › i18n。

アクセシビリティ (a11y)

スクリーンリーダー対応

すべての UI 要素に Semantics widget が付与され、Windows Narrator / NVDA / JAWS / VoiceOver などで読み上げられる。

要素読み上げ例
ノート"テキストノート、内容: 顧客 A の住所、選択中"
接続ハンドル"接続ハンドル、ドラッグして他のノートに接続"
Inspector ボタン"太字、押すとオン"
エラーダイアログ"エラー、保存に失敗しました、OK ボタン"

キーボード操作のみで完結

マウス無しで全機能にアクセス可能。Tab でフォーカス移動、Enter で選択、Esc でキャンセル。詳細: 01-keyboard-shortcuts。

コントラスト

WCAG AA 準拠 (テキスト 4.5:1 / UI 要素 3:1) を目標。Dark / Light 共に検証済 (docs/manual/a11y-verification.md)。

フォントサイズ拡大

操作効果
⌨ Ctrl + + (UI 全体)UI スケール 100% → 110% → 120% → ...
⌨ Ctrl + -下げる
⌨ Ctrl + 0リセット

ノート内テキストは Inspector で個別変更。

モーション軽減

OS の「アニメーション減らす」設定に追従。手動でも Settings → アクセシビリティ → 「モーション減らす」 で OFF 可。

  • ✅ 折りたたみアニメ → 即時切替
  • ✅ ズームのスムージング → カクつき
  • ✅ 起動アニメ → スキップ

高コントラストモード 🚧

Windows の High Contrast Theme を検出 → 専用パレットで描画。検証中。

色覚異常配慮

エッジ / ノート色は 色だけに頼らない 設計:

  • セマンティクスは形 (矢印形状) でも区別
  • 警告は色 + アイコン + ラベル
  • カラーパレットの初期値は色覚多様性を考慮

Tab トラップ

ダイアログを開くと、Tab フォーカスがそのダイアログ内をループ。Esc でキャンセル、Enter で OK。

スクリーンリーダーで使うフロー (一例)

  1. アプリ起動 → Narrator が「HṛdayaFlow、メインキャンバス、空のドキュメント」と読む
  2. ⌨ Tab で Outline → Inspector → Canvas を巡回
  3. Canvas にフォーカス → ⌨ Ctrl + Shift + N でノード種別ピッカー → 矢印で選択 → Enter
  4. ノート編集 → Esc → ⌨ Tab で次のノートへフォーカス移動
  5. ⌨ Ctrl + S で保存 → ステータスバーが「保存しました」と読み上げる

プライバシー

docs/manual/privacy.md 参照。要点:

  • ✅ 既定でテレメトリ無効
  • ✅ クラッシュレポートも opt-in
  • ✅ AI は Ollama (ローカル) を推奨
  • ⚠ PrudeLLM 利用時のみマップ内容が送信される (明示同意必要)

ハイコントラストの扱い

Windows の「ハイコントラスト」設定に、アプリがどう追従するかを選べます。

設定動作
自動（既定）OS の設定に従う。OS が ON なら ON
常に ONOS の設定に関係なくハイコントラスト表示
常に OFFOS が ON でも通常表示のまま

OS 側を切り替えると再起動なしで追従します。
「常に OFF」は、OS をハイコントラストにしているが
このアプリだけは通常配色で使いたい、というときに使います。
