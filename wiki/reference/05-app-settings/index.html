15 アプリ設定

← 14 開発者 | 目次

設定ダイアログでは、表示・Markdown・画像キャッシュ・MCP / AI ターゲットなど、アプリ全体の挙動を調整できます。

画像キャッシュ (ImageCache)

大量の画像ノートを扱うとき、メモリ上に保持するデコード済み bitmap の上限を調整できます。設定変更は再起動不要で即時反映されます。

モード説明
自動（既定）物理 RAM の 1/16、最大 512 MB。RAM 取得不能時は 256 MB
128 / 256 / 512 MB / 1 GB固定上限
RAM/8物理 RAM の 1/8、最大 2 GB。警告ダイアログのうえ opt-in
カスタム32 MB〜2 GB を MB 単位で指定

設定画面には、適用上限・使用中サイズ・件数の診断表示があります。キャッシュをクリアしても Undo やドキュメント本体には影響しません。

Markdown 表示

Markdown ノートの見え方を切り替えます。

項目動作
標準コンパクトな表示
読みやすい行間を広げ、長い Markdown や AI 回答を読みやすく表示
ラスタキャッシュmath / Mermaid などの重い描画を PNG キャッシュして再描画負荷を下げる

AI ライブターゲット

外部 AI（Claude Desktop / Cursor など）が MCP 経由でキャンバスを編集するとき、AI ターゲットの付いた 1 枚のタブへ読み書きが解決されます。

  • AI ターゲットのタブには AI バッジが表示されます。
  • 任意のタブを右クリック → AI にリンク で手動ターゲット化できます。
  • 解除はタブ右クリック → AI のリンクを解除、または AI バッジクリック。
  • AI が新規マップを作った場合や未設定時に AI が動いた場合は、新しいタブが自動でターゲット化されます。

AI 追従

状態動作
オフ（既定）対象タブは更新されますが、表示は切り替わりません
オンAI が編集するたびに対象タブへ自動で切り替え、ウィンドウを前面化します

トレイからクイック追加

システムトレイの HrdayaFlow アイコンを右クリックし、クイック追加を選ぶと小さな入力画面が開きます。複数行を入力でき、Ctrl + Enter（macOS は Cmd + Enter）または 追加でノートを作成します。

  • 追加先は AI バッジの付いた AI ターゲットタブです。
  • AI ターゲットが無い場合は、新しいタブを作って自動的にターゲット化します。
  • ターゲット内でノートが選択されていればその近く、未選択なら末尾ノートの近くへ配置します。
  • トレイを利用できない環境では項目自体が表示されず、通常のアプリ動作には影響しません。

左アクティビティバー

左端のアクティビティバーは、展開 / 折りたたみ状態を保存します。アイコンだけに畳むとキャンバスを広く使えます。

動作確認チェックリスト

  • [ ] ImageCache の上限を変更して即時反映される
  • [ ] Markdown 表示プリセットを切り替えるとノート表示が変わる
  • [ ] AI ターゲットをタブ右クリックで設定 / 解除できる
  • [ ] トレイのクイック追加で AI ターゲットタブへノートが追加される
